# AI Engineer Roadmap, as a website

A searchable, trackable web version of the **AI Engineer Roadmap 2026** by
**[Aditya Dewaskar](https://www.youtube.com/@dewaskaraditya)** (Token Maxr).

> **The roadmap is his work, not mine.** The 24-week structure, the 11 phases, the weekly
> ship deliverables, the 12 portfolio projects and all 314 curated free links come from his
> PDF. This repository is only a different way to read and use it.
>
> Follow him: [YouTube](https://www.youtube.com/@dewaskaraditya) and
> [Instagram](https://www.instagram.com/token.maxr).
>
> If you are Aditya and would like this taken down or changed, open an issue and I will do it.

## What this adds to the PDF

- **Search across every resource.** Type `rag`, `langgraph` or `karpathy` and only the phases
  that match stay open.
- **Filters** by kind (playlists, courses, free books, docs, practice, papers) and a
  **Hindi only** toggle for the 36 Hindi resources.
- **Progress tracking.** Tick weeks, projects and setup steps. Three rings show where you are.
  Progress is stored in your own browser; nothing is sent anywhere.
- **Pick your starting week.** Everything before it dims, so you can use those weeks as a
  checklist instead.
- **Light and dark themes**, and a layout that works on a phone.

## Running it

One file, no build step, no dependencies.

```bash
python -m http.server 8000
```

Then open `http://127.0.0.1:8000`.
